# Орхидея — свадебный салон

Адаптивный сайт-витрина для свадебного салона «Орхидея», Энгельс, ул. Волоха, 15.

## Запуск
Откройте `index.html` в браузере или загрузите папку в репозиторий и включите GitHub Pages.

## Структура
- `index.html` — страницы, тексты и контакты;
- `styles.css` — адаптивный дизайн;
- `script.js` — мобильная навигация, фильтр галереи, просмотр фотографий;
- `assets/photos/*.webp` — оптимизированные изображения для сайта;
- `assets/photos/*-original.png` — исходные фотографии, присланные пользователем;
- `assets/favicon.svg` — иконка сайта.

## Функции
- Mobile-first адаптивная навигация.
- Фильтр фотографий: все / свадебные / вечерние.
- Полноэкранная галерея с клавиатурным управлением.
- Кнопки звонка, WhatsApp, Telegram и 2ГИС.
- SEO title, description и Open Graph.

## Подтверждённые сведения
Название, адрес, телефоны, график, Telegram и перечень направлений сверены с публичной страницей салона, Telegram-каналом и открытыми справочниками. Цены не опубликованы на новом сайте, поскольку их актуальность отдельно не подтверждена.

## Важно перед публикацией
- Уточнить у владельца актуальность телефонов и графика.
- Подтвердить, что ссылка WhatsApp для записи должна вести на номер +7 900 314-00-10.
- Если появятся точные цены, каталог и условия пошива/аренды — добавить их только после подтверждения.
- Формы онлайн-записи и оплаты не подключены; на сайте используются прямые ссылки на звонок, WhatsApp и 2ГИС.
